GHETTO FABULOUS — PLAYABLE SEVEN-DECK CARD TABLE

Upload the CONTENTS of this folder to a NEW GitHub repository subfolder named playable-cards (do not overwrite existing Index.html or visual-playtest).
Entry: playable-cards/index.html

This is a playable 64-space local pass-and-play prototype with seven illustrated decks, matching colored card fronts, collection of rhyme families, 3 choices per lyric role, optional slang bonus, and simple card-driven movement. It is NOT yet a complete integration with the original V6 rhyme-lock/gatekeeper engine. Some original square effects are simplified; physical balancing and performance judging are provisional.

No external dependencies; images must stay in art/ beside index.html.
